# Projeto Agenda API

API REST para gerenciamento de agenda de Contatos.

Esse projeto tem como objetivo melhorar o entendimento do Spring Boot e suas funcionalidades, assim como praticar o desenvolvimento de APIs REST.

## Tecnologias:

- Java 25
- Spring Boot 3.2.5

## Funcionalidades:

- Cadastro de pessoas
- Cadastro de Endereço
